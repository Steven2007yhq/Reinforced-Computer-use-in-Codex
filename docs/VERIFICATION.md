## 本次源码验证

- `npm ci --omit=dev --ignore-scripts`：按锁文件安装 2 个纯 JavaScript 依赖。
- `npm test`：**15 项通过，0 项失败**。包括原有 12 项运行时、提供商协议、
  回环桥接和长页面拼接测试，以及新增 3 项发布检查测试。
- `npm run check:release`：对公开 Git 文件清单检查常见凭据格式、私人用户
  目录、桥接描述文件、配置和观察产物；没有发现命中项。它是启发式检查，
  还配合人工审阅，不能证明任意文本都已经匿名化。
- Windows 安装器的隔离模拟验证：PowerShell 7.6.5 与 Windows PowerShell
  5.1 各 **10/10 项检查通过，0 项失败**。覆盖白名单复制、排除 Git/
  配置/临时文件、方括号路径、备份字节、保留无关 marketplace 内容、
  无 BOM、拒绝覆盖目标、Node/CLI 预检查、根目录冲突与格式/解析。
  测试使用隔离的用户目录和模拟命令，不调用真实 Codex 安装命令，也
  不修改开发设备的个人 marketplace。

运行时测试使用模拟的 CUA 对象与本地测试决策器；桥接测试使用临时回环
服务器；长页面测试使用生成的测试图像。**本次测试没有调用真实 Jev
提供商，也没有完成新的生产网站或原生桌面应用端到端验收。**

## 0.2.0 的历史验收范围

以下来自原插件在 2026-09-24 的本地验收记录，供理解功能来源。本次公开
打包没有重新执行这些浏览器操作，也没有发布原始机器路径和截图。

- 本地浏览器测试页：允许的跨源 frame 动作完成，未授权 frame 交接且
  没有界面修改；敏感控件识别后交由普通 Computer Use 处理。
- 上传/下载与模拟登录使用合成测试材料；验证码只验证识别和交接。
- 自适应 frame 路径使用本地模拟决策客户端；真实 Jev 请求没有验收。
- MDN 上的公开页面搜索和导航曾完成；该环境的一次长页面拼接记录为
  10,127 / 10,135 像素（约 99.92%），末尾 8 像素裁切是当次结果，
  不能当作任意页面的覆盖率保证。

原生 Windows 操作依赖当前会话开放的原生 CUA 工具。个别窗口操作成功
不等于整个应用可用；历史 Multisim 测试中元器件选择器出现阻塞，电路
编辑和仿真没有完成端到端验收，因此本项目没有把 Multisim 标为已兼容。

数据流说明、开源归属、发布检查和 CI 配置。修正文档中对数据不出本机、

通过也不构成 Linux 原生界面兼容性证明。远程 CI 的实际状态应以 GitHub
Actions 页面为准。
